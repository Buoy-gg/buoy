## Install

```bash
npm install @buoy-gg/core @buoy-gg/storage
```

AsyncStorage works as soon as the package is installed. MMKV instances and SecureStore keys have to be registered first; the guide shows how.

The [Storage guide](https://buoy.gg/buoy/latest/docs/tools/storage) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
