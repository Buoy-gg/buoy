## Install

```bash
npm install @buoy-gg/core @buoy-gg/env
```

Env appears in the menu once installed. To check required variables, build the tool with `createEnvTool` and pass it through `apps`.

The [Env guide](https://buoy.gg/buoy/latest/docs/tools/env) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
