## Install

```bash
npm install @buoy-gg/core @buoy-gg/debug-borders
```

Tap the Borders icon in the menu to cycle through off, borders and labels.

The [Debug Borders guide](https://buoy.gg/buoy/latest/docs/tools/debug-borders) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
