## Install

```bash
npm install @buoy-gg/core @buoy-gg/events
```

Events collects from every other Buoy tool you have installed, with no per-source setup.

The [Events guide](https://buoy.gg/buoy/latest/docs/tools/events) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
