## Install

```bash
npm install @buoy-gg/core @buoy-gg/jotai
```

Call `watchAtoms(store, atoms)` once at module scope with your Jotai store and a named map of atoms. Existing atoms stay as they are.

The [Jotai guide](https://buoy.gg/buoy/latest/docs/tools/jotai) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
