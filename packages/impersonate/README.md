## Install

```bash
npm install @buoy-gg/core @buoy-gg/impersonate
```

This tool needs a little config: build it with `createImpersonateTool` and an `onSearchUsers` function that searches your users.

The [Impersonate guide](https://buoy.gg/buoy/latest/docs/tools/impersonate) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
