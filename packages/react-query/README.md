## Install

```bash
npm install @buoy-gg/core @buoy-gg/react-query
```

Render `<FloatingDevTools />` inside your `QueryClientProvider` and the tool picks up your `QueryClient` from context.

The [React Query guide](https://buoy.gg/buoy/latest/docs/tools/react-query) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
