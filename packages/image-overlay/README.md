## Install

```bash
npm install @buoy-gg/core @buoy-gg/image-overlay
```

Copy a frame in Figma, paste it into the tool, and the mockup floats over your running UI.

The [Overlay guide](https://buoy.gg/buoy/latest/docs/tools/image-overlay) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
