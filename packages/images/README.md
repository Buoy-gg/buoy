## Install

```bash
npm install @buoy-gg/core @buoy-gg/images
```

Images appears in the menu once installed. Open it to browse the image loads seen during the session.

The [Images guide](https://buoy.gg/buoy/latest/docs/tools/images) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
