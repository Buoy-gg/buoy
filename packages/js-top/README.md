# @buoy-gg/js-top

A live task manager for the React Native JS thread. It ranks which timers, Promise chains and callbacks are using your JS FPS.

## Install

```bash
npm install @buoy-gg/core @buoy-gg/js-top
```

JS Top is pure JavaScript with no native module. It only runs while the tool is open or Buoy Desktop is watching.

The [JS Top guide](https://buoy.gg/buoy/latest/docs/tools/js-top) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
