## Install

```bash
npm install @buoy-gg/core @buoy-gg/zustand
```

Pass your store hooks to `<FloatingDevTools />` through the `zustandStores` prop. Buoy only subscribes, so your stores don't change.

The [Zustand guide](https://buoy.gg/buoy/latest/docs/tools/zustand) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
