## Install

```bash
npm install @buoy-gg/core @buoy-gg/perf-monitor react-native-reanimated react-native-worklets react-native-performance-toolkit react-native-nitro-modules
```

Bench appears in the menu with a live HUD and a recorder. On web it runs without the native modules.

The [Bench guide](https://buoy.gg/buoy/latest/docs/tools/perf-monitor) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
