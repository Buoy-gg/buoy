## Install

```bash
npm install @buoy-gg/core @buoy-gg/console
```

Console patches `console.*` directly, so there is no logger integration or Babel plugin to set up.

The [Console guide](https://buoy.gg/buoy/latest/docs/tools/console) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
