## Install

```bash
npm install @buoy-gg/core @buoy-gg/route-events
```

Keep your existing navigator and providers. Expo Router and React Navigation are both supported, with different data available for each.

The [Routes guide](https://buoy.gg/buoy/latest/docs/tools/routes) covers setup, what it captures and its limits. New to Buoy? Start with the [Quick start](https://buoy.gg/buoy/latest/docs/quick-start).
