Buoy runs in React web apps with the same tool panels, stores and actions as React Native. React Native Web renders the panels, so your app doesn't need React Native or Expo. Web support is in beta.

## Getting Started

- [Quick Start](./web/quick-start) — install and open the floating menu
- [Installation](./web/installation) — packages, tool setup, routers, Desktop and MCP
